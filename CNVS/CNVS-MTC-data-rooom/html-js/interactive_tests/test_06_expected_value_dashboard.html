CNVS Interactive Projection: Economic Penalty (Slashing) Model

Mathematical Model (Theorem 4): This simulator projects the Expected Value (EV) of an attacker's net profit as a function of the number of critical fragments (m). If the Global Veto rejects the transition, the attacker suffers the economic slashing penalty multiplied by the statistically estimated exposed compromised nodes (m * q). Red bars indicate a strictly negative Expected Value (Break-Even crossed), illustrating the modeled effect of the Truth-Forcing mechanism under the selected parameters.
