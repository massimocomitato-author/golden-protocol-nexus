Displayed mathematical quantity. The curve is not an exact reconstruction probability. It is the Theorem 4 upper bound: B_T4(q) = [q + (1-q) 2^(-h_min)]^m The formal inference relation is p_inf ≤ 2-h_min. This dashboard deliberately saturates that limit and therefore uses the strongest inference probability admitted by the selected entropy margin. The vertical design marker is calculated from: q_max = [η^(1/m) - p_inf] / [1 - p_inf] when a feasible value exists. If even q=0 violates the target, no admissible colluding fraction exists under the selected parameters. At q=1, the bound equals one for every finite m. The optional 33% line is only a classical BFT reference and is not a CNVS tolerance threshold.
