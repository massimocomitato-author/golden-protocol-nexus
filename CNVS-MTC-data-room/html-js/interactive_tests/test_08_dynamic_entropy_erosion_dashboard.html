Heuristic stress profiles. The dashboard assumes: h_1(q)=h_max(1-q), h_2(q)=h_max(1-q)^2, h_4(q)=h_max(1-q)^4 and propagates each profile through: B_T4,a(q) = [q + (1-q) 2^(-h_a(q))]^m The three curves are deterministic upper bounds, not exact reconstruction probabilities. The profiles are exploratory sensitivity assumptions and do not represent measured leakage laws or temporal entropy dynamics. Increasing q simultaneously raises direct compromise exposure and erodes the assumed residual entropy margin; this is a compound adversarial stress assumption. For each profile, q_max is the largest colluding fraction satisfying: B_T4,a(q) <= eta It is found by deterministic bisection. At q=0 all profiles coincide. At q=1 all bounds equal one. The optional 33% marker is only a classical BFT reference and is not a CNVS threshold.
