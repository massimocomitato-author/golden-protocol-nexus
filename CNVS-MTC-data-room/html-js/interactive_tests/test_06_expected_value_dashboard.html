Exact injective proxy versus Theorem 4 upper bound
Analytical model. For each critical-fragment count m, the dashboard enumerates the hypergeometric distribution of the number h of critical fragments assigned to honest verifiers: P(H=h) = C(Q-r,h) C(r,m-h) / C(Q,m) Conditional on h, every honest-assigned critical fragment must be inferred, producing the worst-case reconstruction proxy P_proxy(m) = Σ_h P(H=h) p_inf^h and the exact expected attack payoff E[payoff] = Σ_h P(H=h) [p_inf^h R + (1-p_inf^h)(m-h)L] where R is the successful-attack reward and L ≤ 0 is the slashing applied to each directly compromised critical submitter after a failed attempt. The dashed probability curve is the Theorem 4 upper bound p_compm; it is not used to generate the exact injective curve. Complete critical-set compromise is pessimistically treated as sufficient for reconstruction. The displayed payoff is not complete net profit, and the failed branch is only an analytical proxy for Global-Veto rejection.
